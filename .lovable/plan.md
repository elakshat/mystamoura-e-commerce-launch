# Diwali-wide visual redesign

## Goal
Give Mystamoura a polished, unmistakably Diwali-season presentation across the storefront and admin screens, while keeping the perfume brand legible and all existing behavior unchanged.

## Design direction
Use an editorial festive-luxury style: rich ink and plum surfaces balanced with warm ivory, restrained marigold-gold and vermilion accents, subtle rangoli-inspired line details, and refined EB Garamond/Inter typography. Keep decoration intentional and sparse so product photos, prices, forms, and actions remain clear.

## Work
- Update global semantic theme tokens and shared UI styling so headers, buttons, forms, cards, navigation, and admin screens receive one consistent Diwali treatment.
- Refresh storefront page surfaces, product listings/details, cart, checkout, account, and review UI through shared styling; preserve all interactions and payment overlay positioning.
- Give the homepage a seasonal editorial treatment and a purpose-made perfume-and-Diwali still-life image, without changing its settings-driven content or shopping links.
- Add responsive and reduced-motion-safe festive details without adding heavy animation or visual clutter.

## Validation
Check build/preview health, then inspect the homepage, product browsing, reviews, cart, checkout, and admin surface on desktop and mobile. Confirm readable contrast, no layout overlap, and unchanged checkout behavior. Do not publish unless requested and approved.

## Technical details
Presentation-only changes: global CSS semantic tokens, shared primitives, and focused homepage presentation. No database, authentication, inventory, coupon, review, analytics, or payment-flow changes. Preserve the Razorpay iframe rules and the existing domain verification metadata.
